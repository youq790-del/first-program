# yo7 · 观察小刊编辑助手 0.1.1

这是可加载的 Chrome/Edge MV3 扩展，配合 yo7-wechat-motion 0.5 使用。在公众号后台编辑页显示右侧工作台，可导入 HTML 和安全 SVG。当前是本地首版，不是壹伴的复制品，也未在真实微信账号完成保存验证。

## 安装

1. 解压插件 ZIP，保留整个 `yo7-wechat-editor` 文件夹。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`，启用“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择含 `manifest.json` 的文件夹。
4. 刷新已打开的公众号后台编辑页，点击右侧“yo7 · 编辑助手”或浏览器工具栏图标。

无需公众号 AppID/Secret；未设置模型 API、服务器或账号登录。只申请本地 storage 权限、在 `https://mp.weixin.qq.com/*` 注入界面。不在其他网页自动注入。没有提交草稿、群发或上传图片的隐藏动作。

## 写作流程

1. 在 Codex 中使用 `$yo7-wechat-motion` 生成文章。导入其 `wechat.html` 或完整常显的 `static.html`；不要导入包含控制条的 preview.html。
2. 检查清理报告、图片和手机宽度预览。自有模板也可粘贴 HTML；需把样式写成 inline style，脚本/全局 CSS/网页应用不能随文章执行。
3. “检测正文区域”，从列表确认真正的正文。标题输入框、多个可编辑区域或未知新编辑器，不自动猜测写入。
4. 把光标放回正文，点击“光标后插入”；选中文字时仍插在选区末尾，不删除文字。也可“文末追加”。
5. 局部替换先在目标块放置光标，导入对应块 HTML，点击“替换所选块”；面板先列出目标，第二次点击执行。skill 的 data-yo7-id 优先用于定位整块。
6. 核验当前正文，记录基线，手动保存微信草稿，重新打开后再次确认正文并比较。数量/文字相同不能证明样式、资源、动画在手机有效；继续用微信预览确认。

## 其他功能与边界

- **富文本复制**：直接复制清理后的 text/html；若主剪贴板接口不可用会尝试备用复制。仍失败时明确提示。
- **本地源码**：导入源码按输入自动存 chrome.storage.local，可恢复/清除。当前只有一份本地源码草稿，不按账号同步。正文备份只按需下载；不自动上传。
- **所选块外观**：字号16–22px、宽松行距；图块/SVG/代码应回到源稿调整，防止字体放大破坏关系。
- **撤销**：最多12步插件操作。正文出现后续手工变化时拒绝整篇覆盖，并提供操作前 HTML 备份下载。备份需自己保管。
- **核验**：比较文字 SHA-256、图片/SVG/动画数量、块 ID。记录不带正文全文、账号或 URL 令牌；样式、图片地址和可加载性不在比较范围内。核验基线当前只有一份，请在正确文章中使用。
- **图片**：允许 HTTPS 与位图 data URI 导入；公众号可能重新上传/清理，插件不会替你完成媒体上传。不支持外链 SVG 和脚本。静态公式是内联 path SVG。
- **动态**：保留安全 SMIL，但仍受微信正文限制。取消动画请导入 skill 的静态对应块，不能直接删标签代替完整静态状态。
- **生成能力**：当前不在面板里直接调用模型。自然语言排版和内容判断由 Codex 中的 skill 完成，面板负责预览、送稿与编辑操作。

写入采用浏览器编辑操作并发出 input 通知；编辑器若使用其他内部状态管理，可能不接收 DOM 改动。此时使用“复制富文本”后在公众号内手动粘贴，保存重开核验。页面 DOM 中出现内容不叫“已保存”。扩展尚未安装到用户浏览器，也未发布到应用商店。

## 本地练习与验证

双击 `demo.html` 可使用模拟正文；`self-test.html` 提供不依赖 npm 的本地 DOM 自测。真实浏览器截图、自动化 DOM 测试和微信账号实测分别报告，不能混为一项。

参考 [Chrome content scripts](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts) 与 [壹伴使用方式](https://yiban.io/help?page=help)。实现为本项目原创，没有打包壹伴的私有素材、代码或账号功能。

本轮旧文验证修复了SMIL导入ID的触发问题（0.1.1），已安装本地扩展时需在扩展管理页点“重新加载”并刷新公众号页面。
